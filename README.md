**О проекте**
Веб-страница аукциона «Оно тебе надо» — платформа для необычных лотов, в которые когда-то никто не верил.  

**Структура проекта**
HTML-разметка организована по блочной модели
CSS-стили разделены на:
базовые шрифты
глобальные стили
кастомные стили проекта  

**Основные разделы**
Header с навигацией, логотипом и контактной информацией
Главная секция с уникальным оформлением названия и кнопкой действий
Раздел лотов с карточками объектов
О проекте — описание концепции аукциона
Footer с дублированием контактов и навигации  

**Особенности реализации**
Адаптивная вёрстка
Структурированная система классов
Семантическая разметка
Интеграция социальных иконок
Интерактивные элементы управления  

**Как использовать**
Все стили подключены в head основного файла  

**Структура папок организована логично:**
fonts — шрифты
images — изображения
styles — CSS-файлы
index.html — основной файл
